# 🛠️ Advanced: Editing the Server (Terminal Only)

> [!WARNING]
> **Technical Content Ahead.** This page is for those who want to "get their hands dirty." We are using a GUI-less Linux environment (Ubuntu). If you make a mistake in the code or file paths, the server may fail to boot/be broken forever. Proceed with caution or some expertise in bash (the coding language) and potentially java (also a coding language).

### 📁 The Server Directory

The server is located deep within the Crafty Controller directory. You will need to use **Bash** to navigate here through the terminal in VS Code. Consider the codespace like File Explorer from Windows. But, to move around/select files and such you can't just click around or drag things (well you can kinda drag some things thanks to VS Code, but not like File Explorer). You have to use the terminal which runs on the bash language. You use commands in bash to move up and down in the filer system as well as other commands to enter, select, edit, and do much more to files. 

**The Absolute Path:**
`/workspaces/modding/minecraft/crafty-4/servers/8cc13156-9fae-4975-b3e5-967a40ca91d4`
* An absolute path is like calling a file by its full government name. If you're in a room full with just your friends and you call out your friend by their nickname, you'll all probably know who you're looking for. But if you call out a random nickname at a giant convention, nobody will know who that is. However, if you call them by their full government name and they're wearing a nametag, you'll find them no matter where you are. 

To go there immediately from anywhere in your terminal, type:
`cd /workspaces/modding/minecraft/crafty-4/servers/8cc13156-9fae-4975-b3e5-967a40ca91d4`
* cd means Change Directory... Directories are another name for folders and change directory refers to changing which folder you're currently inside

### 🔍 Essential Bash Commands for Navigation

Since you don't have a mouse-driven file explorer for these deep directories, use these:

* `ls -la`: Lists all files, including hidden ones, with details (ls is list and the letters after the - are called flags. Some commands have flags that change the behavior of the command from the default or enhance it with additional features. If you have two, one-letter flags, you can bunch them all together after a single - where normally you'd have to add a - for each flag like `ls -flag -anotherflag -abc` where *flag*, *anotherflag*, *a*, *b*, and *c* are all different flags).
* `cd ..`: Move up one folder (.. means the one before the one I'm at right now, so saying cd .. means change my directory to the one that comes before this one in the file hierarchy. Another way of saying this is to say the parent file of the current directory or just referring to the folder that the one you're in is inside).
* `pwd`: "Print Working Directory"—shows you exactly where you are if you get lost (to be honest I also use ls to do this and it's quite unwieldy since it gives you the full absolute path).
* `du -sh *`: Shows the file size of every folder (useful for checking if the world size is getting too big. * means anything/everything so if you used command rm which means remove and is used to delete something, then you could type rm `file_a` and it would leave `file_b` alone. But, if you typed something like `rm file_*` it would delete every file that starts with `file_` including `file_a`, `file_b`, and even `file_c` if there is one).

### 📝 Editing Server Files

To change how the server behaves, you will need to edit configuration files. While you can use the VS Code file tree on the left, knowing how to do it in the terminal is faster because of how cluttered/complex all the codespace's necessary files are.

#### **1. server.properties**

This is the "brain" of the server. You can change the difficulty, PvP settings, max players, and view distance.

* **Command:** `nano server.properties`
* **To Save:** `Ctrl + O`, then `Enter`.
* **To Exit:** `Ctrl + X`.
    * Note that nano is a text editor used in consoles (another popular, but much older one is vim) and like everything else in the console/terminal/bash you can't use your mouse to navigate and you must use your arrow keys to move around in whatever file you use nano to edit.

#### **2. Managing Mods**

If you want to add or remove mods from the server:

* Navigate to the mods folder: `cd mods`
* To "delete" a mod: `rm mod-name.jar`
* To download a mod directly from the web to the server:
`wget [URL-OF-THE-MOD-FILE]`
    * wget is a command that downloads the file with that url. You can't feed it the url of the page you go to to download a file. You have to directly right click the download button for the file you're downloading off that page and click `copy link address` and paste that here. However, since we're in VS Code, you could also just navigate to the mods folder and then drag+drop the jar file for the mod there from your computer's File Explorer or wherever you have the mod downloaded. 

#### **3. Reading Logs (Debugging)**

If the server crashes, the answer is always in the logs.

* To see the last 100 lines of the log: `tail -n 100 logs/latest.log`
* To watch the log update in real-time: `tail -f logs/latest.log`

### 🗃️ Key File Structure

* **`/world`**: Contains all terrain and player data. **Never delete this** without a backup.
* **`/config`**: Contains the specific settings for every mod installed. If a mod is acting weird, check here.
* **`whitelist.json`**: The list of players allowed to join.
* **`ops.json`**: The list of players with admin permissions.

### 💡 Pro-Tip: Tab Completion

When typing long paths or filenames in Bash, **press the TAB key**. The terminal will automatically finish the word for you. If it doesn't, it means you made a typo or the file doesn't exist.
