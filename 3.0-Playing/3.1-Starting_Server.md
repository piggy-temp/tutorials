# 🚀 Joining the World

Now that your launcher is set up (and your account may be linked to the Codespace), it’s time to actually play.

### 1. Launch the Game

* **Prism:** Double-click the **Vanilla Perfected** instance or select it and hit **Launch** on the right.
* **XMCL:** Select the pack from the sidebar and hit the **LAUNCH** button.

### 2. Add the Server

Once the game reaches the main menu:

1. Click **Multiplayer**.
2. Click **Add Server**.
3. **Server Name:** Anything you want (e.g., "The Best Server Ever").
4. **Server Address:** `additional-exciting.gl.joinmc.link`
5. Click **Done**, then double-click the server in your list to join.


### 3. How to "OP" Yourself (Admin Powers)
> [!NOTE]
> To do this you and/or someone needs to be linked to the server codespace on VS Code.

If you can't break blocks or want to use cheats (like `/gamemode creative`), you need to make yourself an operator. 

1. Open **VS Code** and connect to the **Codespace**.
2. In the terminal at the bottom, type `sterm` to enter the server console.
3. Type `op YourUsername` (replace `YourUsername` with your actual Minecraft name) and hit Enter.
4. **Important:** Press **`Ctrl + B`** then **`D`** to safely exit the console view without stopping the server.
