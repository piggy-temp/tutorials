# 📦 My Custom Addons

I’ve put together a specific set of extra mods/files that I use to enhance the experience even further. You can grab them from the links below. If there is a folder for the modpack we are using, and there are mods, shaderpacks, or resourcepacks inside, you should probably add them to your instance as well before you try to join the server as those files are mostly all going to be on the server and it will not allow you to join unless you have them.

### 📍 Where to find them

#### **1. Google Drive (Best for all mods)**

I keep a mirror of all my additional mods here.

* **Link:** [Google Drive - Modpacks](https://drive.google.com/drive/folders/1UyETHX6L11r4lcMK0Rury9HMujP7zvcp?usp=sharing)
* *Note: This folder is set to "Comment Only." If you want to suggest an addition, just request permission or add a comment!*

#### **2. GitHub (Best for smaller files)**

I also host a repository for quick access to smaller configs and scripts.

* **Link:** [GitHub Repo - Modpacks](https://github.com/piggy-temp/modpacks)
* **Note on GitHub Files:** You may see a folder called `overrides`. You can **ignore** this—those are specific files I use for the server side only.

### 🚀 How to Install

1. In the Google Drive (if you're more comfortable on Github I'm going to assume you don't need a tutorial or are comfortable Googling it yourself if you can't figure it out...) navigate to the correct modpack. For each of the folders inside click download. 
  *  *Note: To select multiple/all folders to download at once like in the tutorial, click on the first folder name and then hold shift and click on the last folder you're trying to select in the list. Then just press download at the top.*
<img width="1920" height="1020" alt="image" src="https://github.com/user-attachments/assets/12ebdf95-b111-49fc-8f01-c7c4e805ed6a" />
<img width="1920" height="1020" alt="image" src="https://github.com/user-attachments/assets/0e93880e-2605-405a-a275-bbbe5f057ed2" />

2. It will prompt you once it's done being packed into a zip file to select a place to download it to on your computer. Just select an easy place to access like your desktop or downloads folder which can be easily navigated to with one click on the left side of your file explorer (if you're on windows).
<img width="1010" height="546" alt="image" src="https://github.com/user-attachments/assets/42a081fc-70d9-4e68-8e73-b5e224a53e30" />

3. Once you have the folders downloaded, extract all to the current location. Once it's done, a regular folder of the same name as the zip file will appear and you can go in there to select the folders you want to upload to your installation.
<img width="1183" height="571" alt="image" src="https://github.com/user-attachments/assets/3b6c1f42-3942-475d-93dc-d158c8171c0b" />
<img width="1183" height="571" alt="image" src="https://github.com/user-attachments/assets/f9a55cd7-5074-411c-a8ff-cc3e170141f1" />

6. Then ctrl+C the folders and follow the steps in the [Custom Mods Guide](./Custom_Mods.md) to drop them into your instance's folders.
  *  *Note: There's a good chance I will have removed files from the pack so make sure you delete the full folders from the instance files before you paste the ones you've copied from the Google Drive. You can do this by entering the folder you want to delete the files of, then either select all files by using ctrl+A or select the specific files you want to delete by holding ctrl and clicking on the files. Then press delete at the top of the file explorer.*
<img width="1183" height="571" alt="image" src="https://github.com/user-attachments/assets/a93d2e36-99f3-438a-9ccb-1d8e21386944" />

7. Once the files are all deleted, you can copy and paste all the files using a similar method to select the files you want but pressing ctrl+C to copy the files from the Google Drive download and ctrl+V to paste them into the folder you've just emptied out (Excuse the bad cutout, I'm lazy)
<img width="1920" height="883" alt="image" src="https://github.com/user-attachments/assets/4e76037d-9ce4-4399-9e96-a2a0158b9d48" />

8. Now you can feel free to delete the drive files from wherever you had them.
<img width="1183" height="571" alt="image" src="https://github.com/user-attachments/assets/93b36680-0d83-4652-b816-9f5ef36fd91f" />

9. At this point you can feel free to launch or restart the instance to see the new changes!
