# 📦 My Custom Addons

I’ve put together a specific set of extra mods and visual tweaks that I use to enhance the experience even further. You can grab them from the links below.

### 📍 Where to find them

#### **1. Google Drive (Best for all mods)**

I keep a mirror of all my additional mods here.

* **Link:** [Google Drive - Modpacks](https://drive.google.com/drive/folders/1UyETHX6L11r4lcMK0Rury9HMujP7zvcp?usp=sharing)
* *Note: This folder is set to "Comment Only." If you want to suggest an addition, just request permission!*

#### **2. GitHub (Best for smaller files)**

I also host a repository for quick access to smaller configs and scripts.

* **Link:** [GitHub Repo - Modpacks](https://github.com/piggy-temp/modpacks)
* **Note on GitHub Files:** You may see a folder called `overrides`. You can **ignore** this—those are specific files I use for the server side only.

---

### 🚀 How to Install

1. Download the `.jar` files from the Drive or GitHub.
2. Follow the steps in the [Custom Mods Guide](./Custom_Mods.md) to drop them into your instance's `mods` folder.
3. Restart your game (or launch it) to see the changes.
