## 📥 How to Download a Modpack (1.21.11 Fabric)

> [!NOTE]
> Make sure you are searching for the correct platform version (like Modrinth) on the correct mod loader (like Fabric) for the correct Minecraft version (like 1.20.11).

### **Option 1: Prism Launcher**
1.  Open Prism and click **Add Instance** (top left).
<img width="1002" height="789" alt="image" src="https://github.com/user-attachments/assets/a3523d7e-d505-4ce7-9c58-8f33e50967ba" />

2.  Click the correct platform tab on the left sidebar (most prefer Modrinth, but CurseForge is older so it may have more options).
3.  Use the search bar to search for the right pack.
4.  Select the correct result.
5.  On the right side, click **Versions** and ensure you select the correct Minecraft version (look for the release version if possible).
6.  Click **OK** to download.
<img width="915" height="594" alt="image" src="https://github.com/user-attachments/assets/84229236-7a8a-4be5-9f50-56a004a2fe26" />


### **Option 2: XMCL**
1.  Open XMCL and click the **Modpack Market** (store icon) on the left sidebar.
<img width="1020" height="760" alt="image" src="https://github.com/user-attachments/assets/515fd55e-ee07-4a83-9602-47c3bea5dec6" />

2.  Ensure the **SOURCE** at the bottom is set to the correct platform (most prefer Modrinth, but CurseForge is older so it may have more options) by clicking on the other options to cross them out.
<img width="1020" height="760" alt="image" src="https://github.com/user-attachments/assets/13881210-0c12-4646-8254-4845d98bf08f" />

3.  Use the search bar to search for the right pack (pressing enter doesn't do anything, just type what you need and it'll automatically update as you scroll down).
4.  Click the correct result.
<img width="1020" height="760" alt="image" src="https://github.com/user-attachments/assets/685373b5-b41e-4e5b-ad05-b1ddd8968ff2" />
5.  Click the **Install** button.
6.  In the version list that pops up, select the correct Minecraft version (look for the release version if possible) and select the correct mod loader (it must be the same as the modpack.
<img width="1020" height="760" alt="image" src="https://github.com/user-attachments/assets/b46ac1ab-9ce0-4beb-9a0b-3a33ac1c09d0" />

7.  Once finished, the pack will appear in your sidebar ready to launch.
<img width="1020" height="760" alt="image" src="https://github.com/user-attachments/assets/63ddd1ee-887a-40b7-b2be-278b4d724856" />
