# 🐙 GitHub: Why and How

GitHub is essentially a "cloud drive" for code and server files. While you don't *need* an account just to play on the server, having one gives you the "keys to the kingdom."

### ⚠️ The "Burner" Rule

**Important:** I highly recommend creating a **Gmail account** (preferrably a fresh or unused one) to sign up for a **fresh GitHub account** (definitely a brand new one).

* **Why?** We're doing some potentially unsavory stuff here although I don't think it is. If you use a main account you’ve had for years and accidentally trigger somethings or get banned, you lose everything.
* **Keep it separate:** Use a "burner" account so your main digital life stays safe.

---

### ❓ Why do I need this?

1. **Server Control:** I can share the "Codespace" (where the server lives) with your account. This lets you start the server yourself even if I’m asleep or busy.
2. **Easy Addons:** You can download my custom mods and configs directly from the source without dealing with Google Drive.
3. **The Tutorial:** This entire guide is hosted mainly on GitHub. If you have an account, you'll always have the most updated version.

---

### 📝 Setting it Up

1. Go to [GitHub.com](https://github.com/).
2. Click **Sign Up**.
3. Enter your **burner email** and create a password.
4. Choose a username (keep it simple).
5. Verify your email with the code they send you.
6. **Done.** Send me your username so I can share everything with you!
