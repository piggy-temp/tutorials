# 💻 VS Code & Codespaces

VS Code is the window we use to talk to the server. Don't be intimidated by the "coding" look—you’re mostly just going to be typing three specific words to make the server go.

### 🔍 The VS Code Layout

* **The Sidebar (Left):** This has your icons for files, searching, and extensions.
* **The Explorer (Top Left):** This shows you all the files in the folder.
* **The Terminal (Bottom):** This is the most important part. It’s the text box where you type commands to the computer. If you don't see it, press **`Ctrl + ``** (the key next to the number 1).

---

### 🧩 Step 1: Install the Extension

To see my server, you need one specific tool:

1. Click the **Extensions** icon on the left sidebar (it looks like four squares).
2. Search for **"GitHub Codespaces"**.
3. Click **Install**.
4. Sign in to your GitHub account when the pop-up appears in the bottom right.

---

### 🌐 Step 2: Accessing the Server

Once I’ve added your username to the project:

1. Click the **Remote Explorer** icon (it looks like a small computer screen or a plug).
2. In the dropdown at the top, select **GitHub Codespaces**.
3. Under "Shared with me," you should see our server project.
4. Click the **Connect** icon (a small arrow or plug) next to it. It will open a new window that connects to the cloud computer.

---

### 🚀 Step 3: Server Commands (The Big Three)

Once you are connected and the **Terminal** is open at the bottom, you only need to know these three "aliases" (shortcuts):

* **`sstart`**: This starts the Minecraft server. It runs in the background (using something called "tmux"), so it stays online even if you close VS Code.
* **`sterm`**: This opens the "Server Terminal." Use this if you want to see the live console (who is logging in, chat messages, etc.).
* *To leave this view without stopping the server, press `Ctrl + B` then `D`.*


* **`sstop`**: This safely shuts down the server. Use this when we're done playing for the day to save energy/resources.

---

**That's it!** You are now officially a server co-admin. Use your power wisely (or just use it to turn the server on at 3 AM).
