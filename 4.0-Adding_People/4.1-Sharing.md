# 🤝 Inviting Others to the Server

So you want to bring a friend along? Depending on how much "power" you want them to have, there are different levels of access.

### 🥉 Level 1: The Barebones Player

This is for someone who just wants to log in and play. They don't need GitHub, VS Code, or special permissions.

* **What they need:**
1. A third-party launcher (Prism or XMCL).
2. The modpack: **Vanilla Perfected** by **demonjoeTV** (Fabric 1.21.1).
3. The Server Address: `additional-exciting.gl.joinmc.link`



### 🥈 Level 2: The Modded Friend

This is for someone who wants the extra visual "pizzazz" or quality-of-life mods we use.

* **Why share the Drive/Repo:** So they can download the exact `.jar` files and shaderpacks we use without hunting for them online.
* **What to share:** The link to the [Google Drive](https://drive.google.com/drive/folders/1UyETHX6L11r4lcMK0Rury9HMujP7zvcp?usp=sharing) or the [GitHub Repo](https://github.com/piggy-temp/modpacks/tree/main).

### 🥇 Level 3: The Co-Admin

This is for someone you trust to manage the server when you aren't around.

* **Why share the Codespace:** This allows them to use VS Code to run the `sstart` and `sstop` commands. Without this, they can't turn the server on if it's offline.
* **What to share:** You must manually invite their GitHub username to the Codespace environment.

## 👥 Player Capacity

By default, the server is set to a specific number of players to keep things from lagging.

* **How to change it:** If we want to host a big party, someone with "Level 3" access needs to edit the `server.properties` file.
* **Instructions:** See the [Editing Server Page](https://www.google.com/search?q=../3.0-Playing/3.3-Editing_Server.md) for how to use `nano` to change the `max-players` value.
